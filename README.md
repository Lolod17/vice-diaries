Vice Diaries is a static cover studio. Drop in photos, pick one of eight poster layouts, grade the stills, and export a PNG. Photos stay in the browser.

Run it from this directory:

```
python3 -m http.server 4173 --bind 127.0.0.1 --directory app
```

Open http://127.0.0.1:4173. No install and no network once the page is open.

Export sizes: 1080x1080, 1080x1350, 1920x1080.
