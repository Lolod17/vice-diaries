Built from a written specification in a recorded agent session.

Vice Diaries is a static cover-art studio: load photos, pick one of eight poster compositions, grade them as one film, and export a PNG. Run it with `python3 -m http.server --directory app`, then open http://127.0.0.1:8000. Export sizes are 1080x1080, 1080x1350, and 1920x1080. It works offline and never uploads a photo. MIT licence.
